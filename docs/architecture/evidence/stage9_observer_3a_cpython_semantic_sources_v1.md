# CPython 3.12.3: referencja semantyki importów

Źródła referencyjne upstream: [`f6650f9ad73359051f3e558c2431a109bc016664`](https://github.com/python/cpython/commit/f6650f9ad73359051f3e558c2431a109bc016664), wydanie `v3.12.3`.

Tabela wiąże wstępne ustalenia semantyczne z publicznym źródłem i SHA-256 jego pobranych bajtów. Nie jest inventory systemu Dell, obrazem Observera, manifestem runtime ani potwierdzeniem tożsamości Ubuntu-patched CPython. Nie potwierdza obecności żadnego modułu w dokładnym, zaakceptowanym buildzie. Szablony `Setup.*.in` wymagają podstawienia konfiguracji builda; zawartość frozen/builtin musi zostać niezależnie zaakceptowana.

Każda wymieniona krawędź pośrednia ma status `TRANSITIVE_CANDIDATE`, a jej docelowa reprezentacja i obecność pozostają `BUILD_SPECIFIC_UNVERIFIED`. Numery linii odnoszą się do źródeł upstream poniżej, nie do plików systemowego interpretera. Pełne pliki pozostają materiałem roboczym, poza PR.
